# Учебный проект — доска объявлений

Проект по учебному пособию (Часть III — Vue 3).

## Стек

- Vue 3
- Vuetify 3
- Vuex 4
- Vue Router 4

## Запуск

```
npm install
npm run serve
```

## Что реализовано

- Регистрация и логин с валидацией форм
- Навигация меняется в зависимости от того, залогинен пользователь или нет
- Создание, просмотр и редактирование объявлений
- Покупка объявления через модальное окно
- Список заказов
- Защита страниц — без авторизации не зайти
